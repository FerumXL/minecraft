# Установка

## Последняя версия

[Скачать mc112bridge-0.32.0.jar](https://raw.githubusercontent.com/FerumXL/minecraft/codex/offhand1710-bootstrap/releases/0.32.0/mc112bridge-0.32.0.jar)

Что изменилось: [CHANGELOG.md](CHANGELOG.md).

Для Forge **1.7.10-10.13.4.1614**. Закрой игру, помести JAR в папку `.minecraft/mods` профиля Forge и запусти Minecraft. В папке mods должен быть только один файл `mc112bridge-*.jar`. С версии 0.6.0 левая рука работает как в 1.12.2: слот в инвентаре, F меняет предметы в руках, ПКМ использует левую руку, если основная ничего не сделала. В 0.5.0 были клавиши G (обмен) и V (использование).

Сборка из исходников: сначала `python tools/fetch-assets.py` (восстанавливает 1636 файлов Mojang (текстуры, звуки, таблицы добычи, достижения, рецепты) из установленного 1.12.2, по умолчанию из `%APPDATA%\.minecraft`), затем `gradlew.bat build --offline` (Java 8, ForgeGradle 1.2). Для игры нужен `build/release/mc112bridge-<версия>.jar`, а не `build/libs`. Без шага с fetch-assets не будет текстур, звуков, таблиц добычи, достижений и книги рецептов.
