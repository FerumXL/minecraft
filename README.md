# Порт Minecraft 1.12.2 для Forge 1.7.10

Цель проекта — переносить в Minecraft Forge 1.7.10 возможности Minecraft 1.12.2, которые можно реализовать модом без изменений движка. Это отдельный мод контента и совместимости, а не точная копия Minecraft 1.12.2.

## Установка и загрузки

[Страница установки и скачивания](INSTALL.md) · [Последняя версия 0.4.0 (JAR)](https://raw.githubusercontent.com/FerumXL/minecraft/codex/offhand1710-bootstrap/releases/0.4.0/mc112bridge-0.4.0.jar) · [Архив тестовых версий](INSTALL.md#архив-тестовых-версий)

## Принципы переноса

- Добавлять предметы, блоки, рецепты, эффекты и другие возможности, доступные через Forge API 1.7.10.
- Для механик, зависящих от новых систем движка, искать ограниченную совместимую реализацию и описывать отличия.
- Не заявлять полное совпадение или совместимость со всеми модами без проверки.
- Сохранять совместимость с HBM как важную цель; тестировать с установленной версией `HBM-NTM-1.0.27_X5687`.
- Перенос левой руки и полноценного использования предметов в обеих руках остаётся отдельным направлением разработки.

## Текущее состояние

Мод содержит железный самородок, 16 цветов бетона и бетонного порошка, а также 16 вариантов глазурованной керамики. В версии 0.4.0 добавлен магмовый блок с рецептом, уроном при наступании и свечением. Порошок твердеет рядом с водой; поведение при прямом падении/столкновении с водой требует проверки в игре. OptiFine Fast Render вызывает графическую плоскость при падении блока; пользователь подтвердил, что после выключения Fast Render плоскость исчезла.

Совместную работу с HBM и поведение всех блоков нужно проверять в клиенте TLauncher с Forge 1.7.10.
