# Порт Minecraft 1.12.2 для Forge 1.7.10

Мод переносит доступные через Forge возможности Minecraft 1.12.2 в 1.7.10 без изменения движка.

## Установка и загрузки

[Установка и архив версий](INSTALL.md) · [Скачать последнюю версию 0.5.0](https://raw.githubusercontent.com/FerumXL/minecraft/codex/offhand1710-bootstrap/releases/0.5.0/mc112bridge-0.5.0.jar)

Требуется Forge 1.7.10-10.13.4.1614. Установи только один JAR mc112bridge в папку mods.

## Реализовано

- Железный самородок: обмен со слитком и переплавка железного снаряжения.
- Бетон и бетонный порошок 16 цветов.
- Глазурованная керамика 16 цветов с поворотом узора при установке.
- Магмовый блок с рецептом, свечением и уроном при ходьбе.
- Слот левой руки: G меняет его с выбранным предметом, V использует предмет по наведённому блоку, в воздухе или на видимой живой сущности. Обе клавиши переназначаются в настройках управления.

Слот левой руки хранится в данных игрока, синхронизируется по сети, отображается у панели быстрого доступа и в руке игрока от третьего лица. Встроенной модели для первой руки у Minecraft 1.7.10 нет; действие предмета запускается отдельной клавишей V.

## Ограничения и проверки

Совместимость с HBM и многопользовательский режим проверяются отдельно. Fast Render OptiFine ранее вызывал графическую плоскость при падении бетонного порошка; пользователь подтвердил, что после выключения Fast Render артефакт исчез.

Сборка: Java 8, ForgeGradle 1.2. Состояние проверок описано в [матрице](docs/TEST-MATRIX.md).
