# Отличия от Minecraft 1.12.2

Эталон: файлы `1.12.2.jar` и индекса ассетов 1.12 на машине разработчика. Таблица составлена по отчётам аудита и по коду. Столбец «Проверка» говорит, чем подтверждено описание: **автотест** (запуск игры), **код** (только чтение кода), **не проверено**. Учтены прогоны 0.29.0, 0.31.0, 0.32.0 и 0.33.0 (0.33.0 на настоящем jar с OptiFine: `new` 57/0, `reload` 2/0 (138 из 138 блоков), `more` 31/0 и `more2` 2/0 (повтор), `gui` 25/0, `extra` 9/0, `backlog1` 26/0, 0 ошибок GL; на разработческой сборке `new` 57/0, `backlog1` 26/0; 0.32.0: `new` 57, `more` 31, `gui` 25, 0 ошибок GL; полный прогон: `reload` 2 при 138 из 138 блоков, `more2` 2, `extra` 9, `scene` пройден, ни одного FAIL) на настоящем jar с OptiFine (0.31.0: `new` 57, `more` 31, `gui` 25, `reload` 2 при 138 из 138 блоков, `more2` 2, `extra` 9, ни одного FAIL); итоговые цифры прогонов 0.31.0 см. в CHANGELOG. **Скриншот** означает парное сравнение с теми же кадрами из запущенного 1.12.2.

## Что совпало с 1.12.2 по автоматической сверке

Сверка значений из игры с данными jar (скрипт в рабочей папке разработчика, в репозиторий не входит):

- 431 рецепт совпал с реальным результатом крафта. Один рецепт (`spectral_arrow`) пропускался, пока предмета не было; сверка после его добавления также дала 431 совпадение из 431 проверенного.
- Голод и насыщение еды, размеры мобов после появления в мире (проверено на корове), таблицы лута мобов по составу предметов.
- Сделки жителей: 91 запись таблицы из jar, кроме карт, которые создаёт код мода.
