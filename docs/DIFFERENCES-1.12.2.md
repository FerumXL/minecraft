# Отличия от Minecraft 1.12.2

Эталон: файлы `1.12.2.jar` и индекса ассетов 1.12 на машине разработчика. Таблица составлена по отчётам аудита и по коду. Столбец «Проверка» говорит, чем подтверждено описание: **автотест** (запуск игры), **код** (только чтение кода), **не проверено**. Учтены прогоны 0.29.0 и 0.31.0 на настоящем jar с OptiFine (0.31.0: `new` 57, `more` 31, `gui` 25, `reload` 2 при 138 из 138 блоков, `more2` 2, `extra` 9, ни одного FAIL); итоговый прогон 0.31.0 вписывается после завершения (см. CHANGELOG). **Скриншот** означает парное сравнение с теми же кадрами из запущенного 1.12.2.

## Не перенесено

| Что | Причина | Статус |
|---|---|---|
| Поиск в книге рецептов по подсказкам и реестровым именам | Поиск по названию есть с 0.30.0; остальное не сделано | не сделано |
| Вкладки достижений сверх 26 | Не сделаны | не сделано |
| Триггеры достижений `tame_animal`, `brewed_potion`, `enchanted_item`, `construct_beacon`, `cured_zombie_villager`, `item_durability_changed`, `enter_block`, `nether_travel` | Не сделаны | Эти достижения можно получить только через `/advancement` |
| Подбрасывание мобов на кровати и слизи при приземлении | Отскок сделан только для игрока | не сделано |
| Копии иллюзора, караваны и ковры лам, попугай на плече | Упрощения новых мобов (см. CHANGELOG 0.14.0) | не сделано |
| Нарратор, уведомления Realms | К геймплею не относятся | не переносится |

## Что совпало с 1.12.2 по автоматической сверке

Сверка значений из игры с данными jar (скрипт в рабочей папке разработчика, в репозиторий не входит):

- 431 рецепт совпал с реальным результатом крафта. Один рецепт (`spectral_arrow`) пропускался, пока предмета не было; сверка после его добавления также дала 431 совпадение из 431 проверенного.
- Голод и насыщение еды, размеры мобов после появления в мире (проверено на корове), таблицы лута мобов по составу предметов.
- Сделки жителей: 91 запись таблицы из jar, кроме карт, которые создаёт код мода.
