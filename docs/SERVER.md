# Сервер

Мод работает на выделенном сервере Forge 1.7.10. Для всех новых блоков, мобов и механик он нужен и на сервере, и у каждого игрока.

## Установка

1. Java 8 (64-битная, если на сервере будет HBM).
2. Сервер Forge `1.7.10-10.13.4.1614`: установщик Forge с [files.minecraftforge.net](https://files.minecraftforge.net/), пункт «Install server». В папке сервера появятся `forge-1.7.10-10.13.4.1614-1.7.10-universal.jar`, `minecraft_server.1.7.10.jar` и папка `libraries`.
3. Положите `mc112bridge-<версия>.jar` из [releases](../releases/) в папку `mods` сервера. Тот же jar нужен каждому игроку в его `mods`.
4. Первый запуск:

   ```
   java -Xmx2G -jar forge-1.7.10-10.13.4.1614-1.7.10-universal.jar nogui
   ```

   Сервер создаст `eula.txt` и остановится. Прочитайте [EULA Minecraft](https://aka.ms/MinecraftEULA), поставьте в `eula.txt` строку `eula=true` и запустите сервер снова.
5. Настройки лежат в `server.properties`. В мод ничего отдельно настраивать не нужно.

## Кто может зайти

| Клиент | Сервер с модом | Сервер без мода |
|---|---|---|
| с модом той же версии | играет | заходит, работает только клиентская часть: интерфейс и рендер; новых блоков и механик нет |
| без мода | не пускается: `Mod rejections [mc112bridge]` | обычная игра |

Версии мода на сервере и у игроков должны совпадать: новые блоки и предметы получают номера при запуске.

## Флаги отката

Любое изменение поведения можно вернуть к 1.7.10 флагом Java `-Dmc112.*`. Флаг нужно указать там, где работает эта часть: серверный — в строке запуска сервера, клиентский — в настройках Java лаунчера. Полный список с причинами — в [DECISIONS.md](DECISIONS.md). Например:

- `-Dmc112.noTrackSync` (сервер): не присылать состояние левой руки и элитр игроку, который только что увидел другого игрока;
- `-Dmc112.shadow17` (клиент): тени как в 1.7.10.

## Что проверено

На сервере Forge `1.7.10-10.13.4.1614` с этим jar:

- один игрок: левая рука, `/give`, `/title`, мобы, смена рук, элитры, достижения, дракон;
- то же при задержке около 200 мс;
- два игрока видят у друг друга левую руку, броню, элитры и смену рук;
- клиенты с модом и без него, серверы с модом и без него (таблица выше);
- с 1.0.1: сервер и оба клиента с HBM NTM 1.0.27 X5687, новый мир: те же 9 проверок одного игрока и 4 + 4 двух игроков, в журнале сервера ошибок нет.

Не проверено: много игроков одновременно, игра несколько часов подряд, сервер с HBM при задержке.
