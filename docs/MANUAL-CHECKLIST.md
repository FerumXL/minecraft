# Ручная проверка в игре

Здесь только то, что автотесты 0.32.0 не проверяют. Всё остальное подтверждено запуском или сравнением скриншотов с 1.12.2 (см. [CHANGELOG](../CHANGELOG.md) и [отличия](DIFFERENCES-1.12.2.md)).

- [ ] Звуки на слух: новые блоки, мобы, щит, элитры, субтитры совпадают со звуком.
- [ ] Бой с драконом в Крае: огненные шары, облако дыхания, сбор бутылкой, победа, врата.
- [ ] Длительная игра с HBM и OptiFine в существующем мире.
- [ ] Многопользовательский режим: сервер с модом, два игрока, левая рука, щит, достижения.
- [ ] Щит на спине (от третьего лица, когда в руках другой предмет).
- [ ] Вид окна субтитров рядом с субтитрами 1.12.2.
- [ ] Звук уведомления об испытании и звук бутылки с дыханием дракона на слух.
- [ ] Окно альтернатив рецептов рядом с 1.12.2 (эталонного скриншота нет).
- [ ] Изменение размера окна, пока моб светится.
- [ ] Старое сохранение на jar 0.32.0 (на 0.30.0 загрузилось, 97 FPS); деревни в нём остаются старыми.
- [ ] Если лаунчер использует другую Java: режим «Высокая производительность» для её `java.exe`/`javaw.exe` (для `jre1.8.0_281` уже стоит).
- [ ] Деревня пустыни и саванны в новом мире: размер, колодец, дороги, церковь из акациевого бревна (в тесте сверено с 1.12.2 только по блокам и числу построек).
- [ ] Зомби-деревня (1 из 50): без факелов и дверей, зомби-жители. Не проверено, ни разу не выпала.
- [ ] Таёжная деревня: не проверена, в тестовой области не было.
- [ ] Реальная игра с HBM, tlskincape и OptiFine: нет «Ошибка OpenGL: 1283» после 10 кадров; в `latest.log` предупреждение `GlStackGuard` (если есть) и его счётчик; светлые полупрозрачные пятна на земле пропали или остались.
