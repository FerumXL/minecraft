# Ручная проверка в игре

Здесь только то, что автотесты 0.31.0 не проверяют. Всё остальное подтверждено запуском или сравнением скриншотов с 1.12.2 (см. [CHANGELOG](../CHANGELOG.md) и [отличия](DIFFERENCES-1.12.2.md)).

- [ ] Звуки на слух: новые блоки, мобы, щит, элитры, субтитры совпадают со звуком.
- [ ] Бой с драконом в Крае: огненные шары, облако дыхания, сбор бутылкой, победа, врата.
- [ ] Длительная игра с HBM и OptiFine в существующем мире.
- [ ] Многопользовательский режим: сервер с модом, два игрока, левая рука, щит, достижения.
- [ ] Щит на спине (от третьего лица, когда в руках другой предмет).
- [ ] Вид окна субтитров рядом с субтитрами 1.12.2.
- [ ] Звук уведомления об испытании и звук бутылки с дыханием дракона на слух.
- [ ] Окно альтернатив рецептов рядом с 1.12.2 (эталонного скриншота нет).
- [ ] Изменение размера окна, пока моб светится.
- [ ] Старое сохранение на jar 0.31.0 (на 0.30.0 загрузилось, 97 FPS).
- [ ] Если лаунчер использует другую Java: режим «Высокая производительность» для её `java.exe`/`javaw.exe` (для `jre1.8.0_281` уже стоит).
