# Матрица проверок

| Проверка | Кто | Сценарий | Ожидаемый результат | Статус |
|---|---|---|---|---|
| Java и Forge | Codex | Проверить установленное окружение | Java 8 и Forge 1.7.10 | Найдены Java 8 и Forge `10.13.4.1614` |
| HBM | Codex | Зафиксировать версию локального мода | Известна версия для тестирования | Найден `HBM-NTM-1.0.27_X5687.jar` |
| Сборка мода | Codex | `gradlew.bat build` | Компиляция и reobfuscation проходят | Пройдена; предупреждение о source 1.6 |
| Новый мир без HBM | Codex | Запустить `runClient` с модом | Forge загружает мод; новый мир создаётся | Мод успешно загрузился; окно клиента не появилось в UI, создание мира не подтверждено |
| Железный самородок | Codex | Проверить регистрацию, 9 самородков ↔ слиток, переплавку и сохранение | Рецепты работают, предмет сохраняется | Сборка прошла; проверка рецептов в игре не подтверждена |
| Другой переносимый контент | Codex | В новом мире проверить рецепты, блоки, предметы, эффекты, сохранение и повторную загрузку | Нет конфликтов ID и потери состояния | Проверять по мере реализации |
| Левая рука | Codex | В новом мире проверить обмен предметов, еду, размещение и предметы HBM | Нет дублирования, неверного расхода или рассинхронизации | Проверять по мере реализации |
| Совместимость с HBM | Codex | Запустить новый мир с HBM и модом в обычном Forge-профиле | Нет вылета и конфликтов | Dev-запуск упал с `NoSuchMethodError`: HBM обфусцирован, ForgeGradle-среда deobfuscated; нужен запуск обычного профиля |
| Многопользовательский режим | Codex | Проверить обмен и использование на локальном выделенном сервере | Сервер авторитетен, клиент получает корректное состояние | Потребуется отдельный серверный прогон |
| Полная сборка модов | Codex | Запустить новый мир с установленными модами и проверить игровые сценарии | Нет конфликтов и регрессий | Проверю в установленной среде |

Проверки клиента выполняются Codex запуском установленного профиля Forge 1.7.10 на новом тестовом мире. Отдельно отмечу проверки, требующие выделенного сервера или отсутствующих в среде модов.
